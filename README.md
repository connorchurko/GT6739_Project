## Files
### Solitaire.py
This file contains the python script that was used to run the python simulation. There are several inputs that allow the user to decide what set of strategies to use as well as the randomized seeds. The seed value help keep track of initial game states. This was the main file that was used to generate all the data used for the project report.

### Solitaire Data Test 5 300 Limit.xlsx
This excel file contains output data from the Solitiare.py script, specifically for when the maximum move limit was set to 300 moves.

### Solitaire Data Test 6 500 Limit.xlsx

### simulation_charts.py
This file contains the python script that was used to post process the outputted data from the Solitaire.py script. The main purpose of this script was to create charts that would then be used in the project report. This scripts generates more plots than were actually used in the project due to page constraints and their repetitive nature.
